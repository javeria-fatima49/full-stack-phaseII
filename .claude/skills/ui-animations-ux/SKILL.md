# UI Animations & User Experience Skill

## Purpose
Enhance user experience with smooth, meaningful animations without affecting performance.

## Overview
Animations are implemented using Framer Motion to provide visual feedback for user actions.

## Key Patterns
- Animate task creation and deletion
- Smooth transitions between UI states
- Subtle hover and focus animations
- Non-blocking and lightweight motion

## Rules
- Animations must be functional, not decorative
- Avoid excessive motion
- Respect reduced-motion user preferences
