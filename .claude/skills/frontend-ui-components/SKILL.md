# Frontend UI Components & Accessibility Skill

## Purpose
Build reusable, accessible, and responsive UI components using modern frontend tools.

## Overview
UI components are built using Next.js, Tailwind CSS, and shadcn/ui with accessibility and responsiveness as core requirements.

## Key Patterns
- Component-based architecture
- Keyboard navigation support
- Responsive layouts (mobile to desktop)
- Accessible labels and focus states

## Rules
- Avoid inline styles
- Follow WCAG accessibility basics
- Components must be reusable and isolated
